# 🛠 Сервисы и Бизнес-логика

## 💰 Биллинг и Кошелёк (`billing_service.py`)
Центральный узел управления финансами. Работает в асинхронном режиме.

### Основные функции:
- **`add_balance`**: Пополнение баланса. Автоматически создает запись в `transactions`.
- **`spend_balance`**: Списание средств (например, покупка подписки). Проверяет наличие средств, делает атомарное списание и логирует транзакцию.
- **`create_invoice`**: Генерация записи о счете для последующей оплаты через CryptoPay.
- **`update_invoice_status`**: Изменение статуса счета (PENDING -> PAID/EXPIRED).

---

## 👥 Управление пользователями (`user_service.py`)
Отвечает за регистрацию, реферальную систему и права доступа.

### Основные функции:
- **`get_or_create_user`**: Регистрация пользователя. Теперь поддерживает `referrer_id` для привязки рефералов. Содержит защиту от "self-referral".
- **`activate_trial`**: Выдача пробного периода на 24 часа.
- **`get_active_users`**: Кешированный список пользователей с активной подпиской для рассылки алертов.
- **`toggle_user_block`**: Административная блокировка/разблокировка.

---

## 📈 Аналитический движок
- **`worker.py`**: Главный цикл обработки данных.
- **`analyzer.py`**: Логика обнаружения аномалий, каскадных ликвидаций и всплесков OI.
- **`dashboard.py`**: Формирование визуальных отчетов для канала и ЛС.

---

## 🛡 Обработка ошибок
- Используется специфический перехват `SQLAlchemyError` для проблем с БД.
- Внедрено подробное логирование финансовых операций (`logger.info` для успешных, `logger.error` для сбоев).
- Все транзакционные методы гарантируют `rollback()` при возникновении исключений.
