# Gruzbery Screener: Bybit Liquidation Bot

Профессиональное решение для мониторинга ликвидаций на криптобирже Bybit (API V5) в реальном времени. Бот отслеживает аномальную активность трейдеров, суммирует объемы и мгновенно уведомляет пользователей о возникновении «каскадов» или крупных рыночных объемов.

## Ключевые возможности

- **Real-time Monitoring**: Прямое подключение к бирже через WebSocket. Задержка получения данных — миллисекунды.
- **Умная фильтрация**: Система суммирует ликвидации за выбранный период (5 минут или 1 час).
- **Режимы уведомлений**:
  - **LIQ CASCADE** — быстрые ликвидации за 5 минут (паника на рынке).
  - **LIQ VOLUME** — накопленный объем за 1 час.
- **Персональные настройки**: Каждый пользователь через меню `/settings` может установить свой индивидуальный порог срабатывания в USD.
- **Anti-Spam защита**: Интеллектуальный Cooldown (задержка 1 минута) по каждой монете, чтобы не перегружать чат при каскадных движениях.
- **Безопасность данных**: Функция телеграм `protect_content` запрещает копирование и пересылку торговых сигналов из бота.
- **Автоматическая оптимизация**: Встроенная система Retention Policy каждые 4 часа очищает базу данных от старых записей, сохраняя высокую скорость работы.

## 🛠 Технологический стек

- **Язык**: Python 3.11+
- **Библиотека бота**: aiogram 3.x (полностью асинхронная архитектура)
- **Биржа API**: pybit 5.x (официальная библиотека Bybit)
- **База данных**: PostgreSQL 15+ (SQLAlchemy 2.0 + asyncpg)
- **Архитектура**: Producer-Consumer на базе асинхронных очередей.

## ⚙️ Инструкция по конфигурации (.env)

В корне проекта находится файл `.env`. Он содержит все необходимые настройки:

- **BOT\_TOKEN**: API ключ вашего бота от @BotFather.
- **DB\_URL**: Строка подключения к базе данных PostgreSQL.
- **SYMBOLS**: Список монет, за которыми следит бот.

## 📊 Как добавлять новые монеты для мониторинга

Проект спроектирован так, чтобы вы могли легко управлять списком отслеживаемых инструментов без изменения программного кода.

Для добавления или удаления монет:

1. Откройте файл `.env`.
2. Найдите строку `SYMBOLS`.
3. Добавьте тикер нужной монеты в кавычках через запятую. Важно: Тикер должен соответствовать названию пары на Bybit (например, `BTCUSDT`, `ETHUSDT`, `SOLUSDT`).

Пример:

```env
SYMBOLS=["BTCUSDT", "ETHUSDT", "SOLUSDT", "XRPUSDT", "PEPEUSDT", "DOGEUSDT"]
```

1. Сохраните файл и перезапустите бота. Система автоматически подпишется на новые потоки данных.

## Быстрый запуск

### 1. Подготовка базы данных

Убедитесь, что PostgreSQL запущен, и создайте базу данных `bybit_bot`.

### 2. Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Инициализация таблиц

Запустите скрипт один раз для создания структуры БД:

```bash
python -m src.init_db
```

### 4. Запуск системы

```bash
python -m src.main
```

## Структура проекта

- **src/bot/** — интерфейс пользователя, кнопки и логика уведомлений.
- **src/services/** — "двигатель" проекта: подключение к бирже и анализ данных.
- **src/database/** — всё, что связано с хранением и обработкой истории ликвидаций.
- **src/core/** — централизованные настройки и конфигурация.
