# Gruzbery Screener: Bybit Liquidation Terminal

Профессиональная аналитическая система для мониторинга ликвидаций на криптобирже **Bybit (API V5)** в реальном времени. Система построена на высоконагруженной асинхронной архитектуре, позволяющей отслеживать **весь рынок фьючерсов** одновременно без потери данных.

---

## Уникальные особенности и Аналитическая логика

В отличие от простых ботов-лиснеров, Gruzbery Screener использует трехфакторную систему анализа рыночной паники:

### 1. Интеллектуальные типы сигналов
Бот автоматически классифицирует состояние рынка и выбирает заголовок сообщения:
*   **⚡️ LIQ CASCADE (Каскад):** Срабатывает при обнаружении высокой плотности событий (например, 10+ ликвидаций за 60 секунд). Сигнализирует о «эффекте домино».
*   **🔥 QUICK SQUEEZE (Сквиз):** Срабатывает, когда объем за 5 минут составляет значительную часть от часового объема. Признак резкого импульса.
*   **📊 LIQ VOLUME (Объем):** Уведомление о планомерном накоплении крупного объема ликвидаций за 1 час.

### 2. Алгоритм «Smart Threshold» (Анти-спам)
Реализована система **High Water Mark**: бот запоминает объем последнего сигнала и присылает повторный только в случае **роста объема на заданный %** (настраивается в конфиге). Это исключает «засорение» чата при затяжных движениях.

### 3. Пул соединений (Connection Pooling)
Для мониторинга **400+ торговых пар** используется пул из 40+ параллельных WebSocket-соединений. Каждое соединение обслуживает пачку из 10 монет, что гарантирует стабильность и 100% охват рынка без задержек.

### 4. Раздельная аггрегация (Long/Short)
Логика полностью разделена: ликвидации лонгов и шортов считаются в независимых потоках памяти. Бот корректно интерпретирует данные API V5 (Buy = SHORT, Sell = LONG), поэтому сигналы всегда соответствуют графику.

## 🛠 Технологический стек

*   **Python 3.11+** (Asyncio).
*   **aiogram 3.28.2** — современный асинхронный фреймворк для Telegram.
*   **SQLAlchemy 2.0 + PostgreSQL** — надежное хранилище истории и настроек.
*   **Alembic** — система миграций (управление структурой БД без потери данных).
*   **Redis/In-Memory Aggregator** — сверхбыстрые расчеты в оперативной памяти с использованием `collections.deque`.
*   **Docker & Docker Compose** — контейнеризация для быстрого деплоя.

## ⚙️ Конфигурация системы (`.env`)

Проект управляется через переменные окружения. Создайте файл `.env` на основе примера:

```env
BOT_TOKEN=8890049387:AA...         # Токен бота
DB_URL=postgresql+asyncpg://...    # Подключение к БД
IGNORED_SYMBOLS=["BTCUSDT"]        # Черный список монет (не мониторить)

# Параметры алгоритма (Magic Numbers)
ALERT_GROWTH_PERCENTAGE=1.20       # Новый сигнал только при росте на 20%
VOLUME_MULTIPLIER=3.0              # Часовой порог = Порог юзера * 3
GLOBAL_COOLDOWN_SEC=60             # Кулдаун между сообщениями по одной монете
CASCADE_TRIGGER_COUNT=10           # Кол-во событий для статуса "Каскад"
MIN_LIQ_VALUE_FILTER=100.0         # Игнорировать ликвидации меньше $100
```

## Управление монетами

Бот автоматически подтягивает **все** активные USDT-пары с Bybit при старте. Вам не нужно обновлять код при листинге новых монет.
*   Чтобы **исключить** монеты (например, BTC или ETH), добавьте их в `IGNORED_SYMBOLS` в файле `.env`.

## Инструкция по запуску

### 1. Локальный запуск
1. Установите зависимости: `pip install -r requirements.txt`.
2. Примените структуру БД: `alembic upgrade head`.
3. Запустите: `python -m src.main`.

### 2. Запуск через Docker (Рекомендуется для сервера)
```bash
docker-compose up --build -d
```
*Система автоматически создаст базу данных, накатит миграции и запустит мониторинг в фоновом режиме.*

## Команды бота

*   `/start` — Регистрация и приветствие.
*   `/settings` — Интерактивное меню настройки личного порога в $ и переключателей типов сигналов (✅/❌).
*   `/status` — Панель мониторинга: кол-во активных соединений, событий в памяти и статистика сигналов за 24 часа.
